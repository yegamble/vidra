over the compose network behind the shared HMAC boundary. It follows the
platform tag — `deploy/release.sh` cuts the same version in all three component

## Changes

- **"Clear all" deletes history instead of anonymising it.** Anonymising left
  rows behind that the k-anonymity floor could be walked around; this was a real
  bypass, and the fix is deletion.
- **The k-anonymity floor applies to co-visitation neighbours**, not only to the
  query surface.
- **Co-visitation support counters respect retention**, and so do query
  aggregates and engagement.
- **An opt-out means no attributed collection** — the A13 ruling, applied here
  as well as in core and the frontend.
- **Correlation, QoE source truth and retention** (A35) wired through.
- **The migrator no-ops when the ledger is ahead of this binary's migrations**,
  which is the search half of the rollback floor: a clean ledger above the
  newest embedded migration logs one line and exits 0 rather than exiting 1 and
  stranding every service that waits on it. A dirty ledger still fails.
- **CI gates** (A39): supported Go 1.27 pin matching the release image,
  `go mod verify` and `go mod tidy -diff`, one named required check
  `ci-required` over a checked-in manifest, and a skip audit that makes a
  missing dependency fail rather than skip (316 tests, 0 registered skips).
