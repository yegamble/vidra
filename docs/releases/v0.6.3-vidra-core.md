### Migrator behaviour changed

A **clean** ledger above this binary's newest embedded migration is now a no-op
that logs one line and exits 0 (`schema version N is newer than this binary's
newest migration M; nothing to apply`) instead of exiting 1. That is what makes
an app-only `rollback.sh` work: `up -d` starts the migrator one-shots first, and
the old behaviour left every service waiting on a migrator that had failed. A
**dirty** ledger still fails at any version. A `rollback-floor` CI lane runs the
previous release's migrator against this branch's schema.

## Highlights

**Auth.** TOTP replay closed; provider-only accounts can set a password and a
real email behind a step-up that survives the refresh rotation the redirect
causes; no auto-link on a provider email; the second factor is enforced over
SSO; provider secrets move to `env_file`; an unreachable IdP answers a typed
502; admin MFA reset; recovery mail carries a redeemable link and a dead relay
stops leaking account existence; undecryptable MFA secrets fail closed and a KEK
mismatch is surfaced.

**Moderation and administration.** Owner protection and last-admin guard with
typed 422s (`owner_protected`, `last_admin`); ownership transfer;
creator-visible block reasons and unblock notices; quarantine, video blocks and
report context; mute scope covering the channel page, suggestions and the live
rail; instance mutes; watched-word snapshots and triage; role changes reach live
sessions; a tombstone cannot be reactivated; a muted or blocked account cannot
reach an inbox by following.

**Operations.** Process heartbeats and job correlation; health, jobs, audit and
storage dashboards that reflect real operations; drain loops start on the boot
capability rather than a runtime toggle; live reported as setting **and** ingest
capability; `doctor` reads the schema ledger with a command Docker can run;
audit-log retention (`AUDIT_LOG_RETENTION`) and playback-telemetry opt-out.

**Media, storage and CDN.** Stored media carries a content type so the proxy
does not have to guess; the api can be a CDN origin with governing cache
headers; generation-addressed re-transcode; purge families for replacement,
account deletion and download revocation, with retry and audit
(`CDN_PURGE_MAX_ATTEMPTS`, `CDN_PURGE_RETRY_BASE`, `CDN_PURGE_RETRY_MAX`);
constant edge CORS; a storage boot write probe, typed refusals and key
redaction; a storage-migration campaign re-enumerates the source; a missing
object is a 404 and never a cached one.

**Scanning.** Scan by default — `CLAMAV_ADDR` turns it on, `MALWARE_SCAN_ENABLED`
is deprecated and no longer read. Every user-supplied file is in scope. Infected
originals are dropped and a scanner health component is reported.
`MALWARE_SCAN_MODE` = `fail-closed` (default) / `fail-open` / `quarantine` /
`disabled`; the last is the documented opt-out and writes one
`system.malware_scan.disabled` audit row per boot.

**Live.** The bundled RTMP plane runs on one nginx worker so a termination
reaches the publisher; `LIVE_INGEST_CONTROL_URL` (requires `LIVE_INGEST_SECRET`)
is core's only outbound path to the ingest and adds a `live_ingest` health
component; verified drop; watchdog disconnect; audited ends;
`LIVE_RECORDING_RETENTION` finally deletes finished sessions' `.flv` files.

**Federation.** Remote videos play against the origin; the AP object id is
dereferenceable; account-scoped retroactive blocks; a blocked instance's
`Follow` is answered with a signed `Reject` while the block stands; comment
`Create`s cancelled inside a block window resume and arrive exactly once; the
mirrored thread is threaded; a video no peer was ever sent is never retracted;
the watched-word queue names the *remote* author of a federated comment.

**Import.** URL import, yt-dlp platform import and channel auto-sync, with
`IMPORT_FETCH_TIMEOUT` / `IMPORT_FETCH_IDLE_TIMEOUT` budgets and
`CHANNEL_SYNC_*` backoff.

**IPFS.** Health-gated redirects (`IPFS_HEALTH_PROBE_INTERVAL`), real reconcile,
unpin on block that restores the whole HLS tree on unblock, `IPFS_GC_AFTER_UNPIN`,
pins swept when a video is deleted, strays counted where the component is read.

**ATProto.** Identity login is reachable (dev loopback hops and the identity
routes); `ATPROTO_PLC_URL` has a consumer in both role maps.

**Dependencies.** `golang.org/x/oauth2` 0.36.0 → 0.37.0, `golang.org/x/crypto`
0.55.0 → 0.56.0, `github.com/coreos/go-oidc/v3` 3.20.0 → 3.21.0.
